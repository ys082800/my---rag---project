# 1.  AI 문서 Q&A 에이전트

본 프로젝트는 PDF 문서를 업로드하면 문서의 내용을 분석하고,
사용자가 입력한 질문에 대해 문서에 포함된 정보를 기반으로 답변을 제공하는
AI 문서 질의응답(RAG) 에이전트입니다.

PDF에서 텍스트를 추출한 후 텍스트를 청크 단위로 분할하고,
OpenAI Embedding을 활용하여 문서 내용을 벡터화한 뒤 FAISS에 저장합니다.
사용자의 질문이 입력되면 관련 문서 내용을 Retriever를 통해 검색하고,
검색된 내용을 Prompt에 전달하여 GPT-4o가 문서 기반 답변을 생성합니다.

본 프로젝트에서는 프롬프트를 여러 버전으로 실험하고 결과를 비교하여
최종적으로 Prompt C를 선정하였으며, Streamlit Cloud를 통해
웹에서 직접 실행할 수 있도록 배포하였습니다.

## 4. 주요 기능 설명

### 1. PDF 문서 업로드
사용자가 Streamlit 웹 인터페이스를 통해 PDF 문서를 업로드할 수 있습니다.

### 2. PDF 텍스트 추출
업로드된 PDF 문서에서 PyMuPDF를 사용하여 텍스트를 추출합니다.

### 3. 문서 분할 및 임베딩
추출된 텍스트를 일정한 크기의 청크로 분할하고,
OpenAI `text-embedding-3-small` 모델을 사용하여 문서 내용을 벡터로 변환합니다.

### 4. 벡터 데이터베이스 구축
생성된 임베딩을 FAISS에 저장하여 문서 내용을 검색할 수 있도록 구성합니다.

### 5. 관련 문서 검색
사용자의 질문이 입력되면 Retriever를 통해 질문과 관련성이 높은 문서 청크를 검색합니다.
현재 Retriever의 검색 개수는 `k=5`로 설정되어 있습니다.

### 6. 문서 기반 답변 생성
검색된 문서 내용을 Prompt에 전달하고,
OpenAI `GPT-4o`를 이용하여 업로드된 문서를 기반으로 답변을 생성합니다.

### 7. 프롬프트 비교 및 최종 프롬프트 선정
문서 기반 답변의 품질을 향상시키기 위해 여러 프롬프트 버전을 비교하고,
실험 결과를 바탕으로 최종 Prompt C를 선정하여 적용했습니다.

### 8. 웹 서비스 배포
Streamlit Community Cloud를 이용하여 개발한 AI 문서 Q&A 에이전트를 웹에서 실행할 수 있도록 배포했습니다.

## 7. RAG 처리 과정

본 프로젝트는 PDF 문서를 기반으로 관련 정보를 검색한 후,
검색된 문서 내용을 GPT-4o에 전달하여 답변을 생성하는 RAG(Retrieval-Augmented Generation) 구조로 구현되었습니다.

### 1. PDF 문서 로드

사용자가 Streamlit UI를 통해 PDF를 업로드하면 PyMuPDF를 이용하여
PDF 문서의 텍스트를 추출합니다.

### 2. 텍스트 분할

추출된 전체 문서를 `RecursiveCharacterTextSplitter`를 이용하여
여러 개의 청크로 분할합니다.

현재 설정은 다음과 같습니다.

- Chunk Size: `400`
- Chunk Overlap: `50`

### 3. 문서 임베딩

분할된 각 청크를 OpenAI의
`text-embedding-3-small` 임베딩 모델을 이용하여 벡터로 변환합니다.

### 4. 벡터 데이터베이스 구축

생성된 임베딩 벡터를 FAISS에 저장하여
질문과 관련된 문서 내용을 검색할 수 있도록 구성합니다.

### 5. 관련 문서 검색

사용자가 질문을 입력하면 Retriever가 FAISS에서
질문과 관련성이 높은 문서 청크를 검색합니다.

현재 검색 개수는 `k=5`로 설정되어 있습니다.

### 6. 프롬프트 구성

검색된 문서 내용과 사용자의 질문을 Prompt C에 전달합니다.

Prompt C는 문서에 제공된 정보만을 근거로 답변하도록 구성되어 있으며,
문서에 없는 내용을 추측하지 않도록 제한합니다.

### 7. 답변 생성

검색된 문서 내용과 사용자의 질문을 입력받은 GPT-4o가
문서 기반 답변을 생성합니다.

### 8. 사용자에게 답변 제공

생성된 답변은 Streamlit UI를 통해 사용자에게 출력됩니다.

### 전체 처리 흐름

PDF 업로드
→ PyMuPDF 텍스트 추출
→ 텍스트 분할
→ OpenAI Embedding
→ FAISS 저장
→ Retriever 검색
→ Prompt C
→ GPT-4o
→ 답변 생성
→ 사용자 출력


## 8. 프롬프트 실험 및 최종 프롬프트 선정

문서 기반 질의응답의 답변 품질을 향상시키기 위해 서로 다른 지침과 출력 형식을 적용한
프롬프트 A, B, C를 작성하고 동일한 문서를 대상으로 비교 실험을 진행했습니다.

### 실험 목적

프롬프트의 구성과 출력 형식에 따라 문서 기반 답변의
정확성, 완전성, 관련성, 근거성 및 가독성이 어떻게 달라지는지 확인하고
최종적으로 서비스에 적용할 프롬프트를 선정하는 것을 목적으로 했습니다.

### 비교 대상

| 구분 | 특징 |
|---|---|
| Prompt A | 기본적인 문서 기반 답변 지침과 핵심 답변 중심의 출력 형식 |
| Prompt B | 질문의 요구사항을 빠짐없이 답변하도록 지침을 강화하고 상세한 출력 구조 적용 |
| Prompt C | 문서 분석 역할을 명확하게 지정하고 핵심 답변, 상세 설명, 주요 내용, 근거를 구분하여 출력하도록 구성 |

### 실험 조건

동일한 PDF 문서와 동일한 질문을 사용하여 프롬프트별 답변을 비교했습니다.

주요 RAG 설정은 다음과 같습니다.

- Chunk Size: `400`
- Chunk Overlap: `50`
- Retriever `k`: `5`
- Embedding: `text-embedding-3-small`
- LLM: `GPT-4o`
- Temperature: `0`

### 비교 결과

세 프롬프트 모두 문서에 포함된 핵심 정보를 검색하고 답변하는 데에는
큰 차이가 없었지만, 답변의 구성과 정보 제시 방식에서 차이가 나타났습니다.

| 평가 항목 | Prompt A | Prompt B | Prompt C |
|---|---|---|---|
| 정확성 | 비교적 안정적 | 안정적 | 안정적 |
| 완전성 | 기본적인 답변 | 요구사항을 비교적 충실하게 반영 | 질문의 요구사항과 세부 내용을 함께 제시 |
| 관련성 | 핵심 내용 중심 | 상세한 답변 | 핵심 내용과 세부 내용의 균형 |
| 근거성 | 근거 제시 | 근거 제시 | 별도의 근거 항목을 통해 명확하게 제시 |
| 가독성 | 간결함 | 상세한 구조 | 핵심 답변 → 상세 설명 → 주요 내용 → 근거의 구조 |

### 최종 프롬프트 선정

비교 결과 Prompt C를 최종 프롬프트로 선정했습니다.

Prompt C는 문서 기반 답변이라는 역할과 제약조건을 명확하게 지정하고,
답변을 `핵심 답변`, `상세 설명`, `주요 내용`, `근거`로 구분하여
사용자가 필요한 정보를 빠르게 확인할 수 있도록 구성했습니다.

따라서 현재 서비스에는 Prompt C를 적용하여 문서 기반 질의응답을 수행하도록 구현했습니다.
